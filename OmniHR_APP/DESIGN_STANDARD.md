# OmniHR Mobile Design Standard

## Direction

OmniHR mobile is an operational HR tool. The UI should feel calm, compact, and
work-focused. Prefer clear hierarchy and predictable controls over decorative
effects.

## Rules

- Use the web palette: blue `#1971C2`, green `#12B886`, amber `#F59F00`, navy
  `#243B6B`.
- Keep surfaces white on `#F5F7FB`; use light blue/green tint only for page
  background.
- Use `8px` radius for cards, inputs, buttons, menus, and navigation surfaces.
  Pills may stay fully rounded.
- Use one shadow level only, and keep it soft. Avoid large glow effects.
- Use gradients sparingly: brand strip, splash, or a single visual panel only.
- Keep login and forms compact: logo, title, subtitle, fields, primary action,
  optional settings.
- On mobile, the form is the product. Images are secondary and should not crowd
  the first screen.
- Status colors carry meaning; avoid using amber/purple as decoration.
- Use icons to support scanning, but do not make every row visually loud.
- Dense enterprise pages should prefer panels, rows, and lists over marketing
  hero layouts.
